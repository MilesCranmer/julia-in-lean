# Responses to the review of Compiler_src_tfuncs

Each `*Spec` named in an entry is now the conjunction of the earlier statement (renamed `*Base`,
in `JuliaLean/Proofs/Compiler/src/tfuncs/Specs.lean` or `Nothrow.lean`) and new branch clauses in
`JuliaLean/Proofs/Compiler/src/tfuncs/SpecsBranches.lean`. No statement was weakened. Sub-calls
that run the partial subtyping and type-construction loops (`hasintersect`, `isconcretetype`,
`jlTuple`, ...) appear as hypotheses on what they return, so each clause fixes the branch's
result given its sub-calls' results.

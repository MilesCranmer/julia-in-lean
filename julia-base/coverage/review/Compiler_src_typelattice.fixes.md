| 14 | `narrow_limited_typ` | Strengthened `compiler-tl-narrow-limited-typ`. The causes are now pinned exactly: `c ∈ cs ↔ c ∈ causes x ∨ c ∈ causes y`, from the new lemma `idsetUnion_mem`. On the mirror objection: the model does give IdSets identities (`causesId : ObjId`), and `copy` allocates a fresh id from the counter. The statement now pins the result's set id to the freshly allocated `s` and the new state to `s + 1`.
